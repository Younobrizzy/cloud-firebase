GMAIL SMTP SETUP

Cloudflare variables:
Text:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USERNAME=your@gmail.com
CONTACT_TO=your@gmail.com

Secret:
SMTP_PASSWORD=your 16-character Gmail App Password

IMPORTANT:
1. Use a Gmail App Password, not your normal Gmail password.
2. Gmail App Passwords require 2-Step Verification.
3. This version uses Gmail implicit TLS on port 465.
4. Do not use port 587 with this version.
5. Do not put SMTP_PASSWORD in GitHub or frontend JavaScript.
6. Keep the Function at functions/api/contact.js.

The frontend calls:
POST /api/contact

The Function connects directly from Cloudflare Workers to:
smtp.gmail.com:465
